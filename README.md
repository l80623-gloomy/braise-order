# braise-order

醇滷味 Q 版互動點餐網站。

客人用手機掃 QR Code 進入，從一整排竹菜單牌點選滷味，選好辣度與配料後，Q 版食材會跳進麵切；業者設定取餐時間，煮好後按「完成訂單」，客人手機上會播放食材從麵切倒進明清青花大碗公的動畫。

## 畫面

| 頁面 | 使用者 | 功能 |
|---|---|---|
| `index.html` | 客人（手機） | 竹牌點餐、配料選擇、投入麵切動畫、等候倒數、倒入碗公動畫 |
| `admin.html` | 業者 | 訂單看板、設定 5／10／15 分鐘、完成訂單 |

## 技術

- Vite ＋ 原生 JavaScript（ES Modules）
- GSAP 動畫
- 訂單同步：第一階段以 BroadcastChannel 模擬（同一台電腦兩個分頁），後端待定（傾向 Firestore）
